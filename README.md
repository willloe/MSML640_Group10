# MSML640_Group10: Slides-AI (monorepo)

This project implements a two-part system that helps users turn messy or plain slide decks into readable, visually consistent presentations **without** relying on rigid templates:

1. **Slide Understanding Module (Classifier)**
   Detects visual components (diagrams, images, logos) and classifies text regions (e.g., Title, Caption, Body) to build a structured layout graph for each slide.

2. **Layout-Aware Diffusion Module (Diffusion)**
   Uses the layout together with a style prompt + color palette to generate slide-safe backgrounds that keep text regions smooth and high-contrast.

The main diffusion pipeline lives under **`packages/diffusion/`**.

## Data Setup

By default, the diffusion pipeline expects:

- **Describable Textures Dataset (DTD)** images flattened under something like:
  - `packages/diffusion/dataset/images_flattened/`
- **Synthetic layouts and safe-zone masks** generated by Javad's scripts under:
  - `packages/diffusion/dataset/synthetic/` (or similar subfolders)

If you are reproducing the project on a fresh machine:

1. Download or regenerate the synthetic layouts using the scripts in `packages/diffusion/Javad/`.
2. Ensure the dataset paths referenced in `Diffusion_Pipeline.ipynb` (and/or `src/diffusion_pipeline.py`) match where your images and JSON files actually live.

## Running the Diffusion Pipeline

The diffusion code lives under `packages/diffusion/`.

### Jupyter / Colab Notebook

1. Open `packages/diffusion/Diffusion_Pipeline.ipynb` in VS Code, Jupyter Lab, or upload it to Google Colab.
2. Make sure the Python kernel is using the virtual environment (or a Colab runtime with GPU).
3. Run the notebook **top to bottom**. The notebook:
   - Loads SDXL + LoRA configuration.
   - Loads DTD textures and synthetic layout/mask datasets from `packages/diffusion/dataset/`.
   - Generates A/B comparisons between the **baseline** SDXL and the **layout-aware** SDXL+LoRA+ControlNet model.
4. Generated images and metrics are written under `outputs/` (e.g., `outputs/lora_ab/`).

You can quickly test the generation with the provided `sample_layout.json` and `sample_palette.json` at the repo root by pointing the notebook to those files.

**For detailed instructions, see:**  
[Diffusion Pipeline README](packages/diffusion/README.md)

## Running the Classifier Pipeline

The classifier module analyzes presentation slides to detect and classify different components including text, charts, shapes, diagrams, images, and logos. The output is a structured JSON layout.

### Option 1: Run Complete Integrated Pipeline

For end-to-end slide analysis with all classifier components:

**Navigate to the integrated pipeline:**
```bash
cd packages/classifier/Javads_part_640/testing_inference
```

**Run the pipeline:**

For **slides** (charts, images, logos, text):
```bash
python run_inference.py --pipeline slides --conf 0.25
```

For **diagrams** (charts, diagram nodes, text):
```bash
python run_inference.py --pipeline diagrams --conf 0.25
```

**Models used:**
- `graphs/best.pt` - Charts & shapes detection
- `images_logos/best.pt` - Images & logos detection
- `nodes/best.pt` - Diagram nodes detection (diagrams pipeline only)
- Text extraction - OCR + classification

**Output:**
```
packages/classifier/Javads_part_640/testing_inference/results/
├── results.json          # Detection statistics
├── visualizations/       # Annotated images
└── layouts/             # Individual slide JSONs
```

**For detailed instructions, see:**  
[Integrated Pipeline README](packages/classifier/Javads_part_640/testing_inference/README.md)

## Detected Elements

The integrated classifier pipeline detects the following elements:

**Charts & Shapes** (23 classes):
- column, line, pie, bar, area, scatter, histogram, waterfall
- flowchart, hierarchy, shapes, tables

**Images & Logos** (2 classes):
- logo, images

**Diagram Nodes** (1 class):
- diagram_node

**Text** (5 types):
- Title, Caption, Obj-text, Other-text, Page-text
